# Crypto Radar TH

เว็บแอปวิเคราะห์เหรียญคริปโต ราคาเรียลไทม์จาก Binance TH ทุกเหรียญ
กราฟหลายจอ · แนวรับ-แนวต้าน · คะแนนน่าซื้อ (เทคนิค + ข่าว + อารมณ์ตลาด) · Backtest · แจ้งเตือนราคา / เหรียญดีด / ข่าวลบ ผ่านเบราว์เซอร์

เป็นไฟล์ HTML ไฟล์เดียว (`index.html`) ไม่ต้องติดตั้งอะไร ไม่พึ่ง CDN รองรับมือถือ และติดตั้งเป็นแอปบนหน้าจอโทรศัพท์ได้

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด |
| `gas/Code.gs` | โค้ด Google Apps Script (ดึงข่าว RSS + Gemini + proxy Binance TH) — ไม่บังคับ |
| `manifest.webmanifest`, `icon-*.png`, `icon.svg` | ไอคอนและข้อมูลสำหรับ “เพิ่มไปยังหน้าจอโฮม” |
| `CNAME` | โดเมนของเราเอง (แก้เป็นโดเมนจริงก่อนใช้) |
| `.nojekyll` | บอก GitHub Pages ไม่ต้องแปลงไฟล์ |

## การตั้งค่า GAS (ไม่บังคับ)

1. เปิด script.google.com → โปรเจกต์ใหม่ → วางโค้ดจาก `gas/Code.gs`
2. เรียกใช้ฟังก์ชัน `testNews` หนึ่งครั้งเพื่ออนุญาตสิทธิ์
3. (ถ้าต้องการ AI) คุณสมบัติของสคริปต์ → `GEMINI_API_KEY`
4. ทำให้ใช้งานได้เป็นเว็บแอป (ทุกคนเข้าถึงได้) → คัดลอก URL `/exec`
5. เปิดเว็บ → แท็บ 🛠 ตรวจระบบ → วาง URL → บันทึก

> ห้ามใส่ API Key ลงในไฟล์ในรีโปนี้ เพราะรีโปสาธารณะใครก็เปิดอ่านได้ — คีย์เก็บไว้ใน GAS เท่านั้น
> URL ของ GAS เก็บในเบราว์เซอร์ของผู้ใช้แต่ละคน (localStorage) ไม่ได้อยู่ในโค้ด
