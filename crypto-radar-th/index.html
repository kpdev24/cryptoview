ตั้งค่าแหล่งข้อมูล

วิธีติดตั้ง GAS v3 (ข่าว + Gemini + Proxy) ประมาณ 5 นาที
  1. เปิด script.google.com → โปรเจกต์ใหม่ → วางโค้ดด้านล่างแทนของเดิม แล้วบันทึก
  2. เลือกฟังก์ชัน testNews แล้วกด ▶ เรียกใช้ → อนุญาตสิทธิ์ → ดูผลใน “บันทึกการดำเนินการ” ว่าดึงข่าวได้
  3. (ไม่บังคับ) ⚙️ การตั้งค่าโปรเจกต์ → คุณสมบัติของสคริปต์ → เพิ่ม GEMINI_API_KEY = คีย์จาก aistudio.google.com/apikey
  4. ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป · เรียกใช้ในฐานะ “ฉัน” · สิทธิ์เข้าถึง “ทุกคน” → คัดลอก URL /exec
  5. วาง URL ในช่องด้านบน กดบันทึก แล้วกดทดสอบการเชื่อมต่อ
  6. แก้โค้ดภายหลัง ต้อง “จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่” ไม่อย่างนั้น URL เดิมยังใช้โค้ดเก่า
